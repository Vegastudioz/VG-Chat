# VG Chat
### Premium FiveM Chat System by Vega Studio

VG Chat is a modern and feature-rich chat system designed to enhance communication and roleplay interactions in FiveM servers.

Built with a clean interface, smooth animations and immersive roleplay features, VG Chat provides a more engaging communication experience while keeping performance and customization in mind.

---

## ✨ Features

- **Modern UI:** Clean, premium and animated chat interface.
- **Emoji Support:** 2,359 built-in Unicode emojis.
- **Command Suggestions:** Dynamic command suggestions with configurable options.
- **Roleplay Commands:**
  - `/me` – Display character actions.
  - `/do` – Describe situations and surroundings.
  - `/ame` – Display actions above your character.
- **Private Messages:** Send private messages using `/pm`.
- **Dice System:** Use `/zar` or `/roll` to roll a synchronized dice.
- **Overhead Animations:** Animated roleplay messages displayed above player characters.
- **Typing Indicator:** Animated typing indicator when players open the chat.
- **Message Management:** `/clear` to clear the chat.
- **Multiline Support:** Roleplay messages automatically stack above each other.
- **Configurable Positioning:** Adjust overhead message height through configuration.
- **Optimized Experience:** Designed for smooth operation and minimal unnecessary resource usage.

## 📥 Installation

**1. Download**

Download the latest version of VG Chat from this repository.

**2. Extract**

Extract the downloaded archive into your server's resources directory.

Example:

```text
resources/
└── [vega-studio]/
    └── vg-chat/
```

**3. Install Dependencies**

Make sure `screenshot-basic` is installed and properly configured on your server.

**4. Server Configuration**

Add the following lines to your `server.cfg`:

```cfg
ensure screenshot-basic
ensure vg-chat
```

**5. Restart**

Restart your server or execute:

```text
restart vg-chat
```

VG Chat should now be running on your server.
